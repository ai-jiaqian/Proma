# Proma v0.19.5-jq.1 Release Notes

## 同步官方 v0.19.5（v0.19.1 → v0.19.5，5 个提交）

### Bug 修复

- **修复 LiveMarkdown 渲染回归**（#1912）— 恢复 LiveMarkdown 实时渲染内核的正常渲染，修复公式、表格、语法高亮等场景的显示问题，Vault 笔记编辑器与项目记忆编辑直接受益。
- **修复预览选区引用回归**（#1913）— 恢复选中内容引用到聊天的功能，选区引用与划词操作恢复正常。
- **规范化 Google Pi base URL**（#1914）— 自定义 Google / Gemini API 端点时自动规范化 base URL，减少配置踩坑。
- **队列消息保持流式路由**（#1910）— 排队中的消息发送后保持原有流式路由 owner，不再走错通道。
- **Agent 终端优先复用可见终端**（#1911）— Agent 需要终端时更倾向复用当前可见终端，减少终端堆积。
