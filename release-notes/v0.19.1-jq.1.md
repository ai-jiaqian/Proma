# Proma v0.19.1-jq.1 发版草稿 Notes

> 生成于 2026-08-29（参谋草稿，待用户拍板同步后使用）。
> 基线：官方 v0.19.1（upstream `18d41b55`）；fork 自 `v0.18.2-jq.1` 起 0 个自有提交，本版全部内容为同步官方 v0.19.1。

## 同步官方 v0.19.1（v0.18.2 → v0.19.1，54 个提交）

### 新功能

- **Obsidian Vault 集成** — 会话侧边栏新增 Obsidian 笔记工作区：可切换 Vault、按文件树浏览与管理笔记，支持新建/重命名/删除笔记与文件夹。编辑器基于 LiveMarkdown 实时内核，渲染双链引用 chip、Properties 与代码块高亮，笔记自动保存；原 Scratch Pad 自动迁移进托管 Vault，聊天侧边栏与 Agent 上下文也能感知 Obsidian 笔记。
- **Office 文件高保真预览** — 为 DOCX、XLSX、PPTX 打包 OfficeCLI，在子进程中渲染高保真 HTML 预览并以 iframe 隔离展示；构建时校验并固定平台对应的 OfficeCLI 资源，原有渲染器保留为兜底。
- **MCP 与 CLI 连接目录** — 新增统一连接目录，内置常用服务提供商条目与本地品牌图标，支持安全凭证流与 OAuth 管道；手动设置提示同步完善，MCP 服务器接入更直观。
- **MCP 与 Skills 侧边栏入口整合** — MCP 与 Skills 管理入口收敛到统一侧边栏路径，离开详情页时自动落盘变更。
- **右侧工作区双 Pane 并排查看** — Agent 右侧工作区支持双 Pane 并排查看，窄栏下自动切换单列布局，折叠侧边栏后仍可完整展开。
- **从目录直接打开终端** — 项目文件夹与改动面板目录支持一键在嵌入式终端打开；附加目录根及其子目录也提供终端入口，并以对应目录作为工作目录；Agent 运行时复用可见终端，减少终端堆积。Windows 终端可选择 shell profile（pwsh / git-bash / wsl / cmd）。
- **LiveMarkdown 覆盖项目记忆** — 项目记忆、自动化任务 prompt 等 Markdown 场景统一切换为 LiveMarkdown 实时编辑/预览内核，代码高亮对齐 Shiki。
- **生产力工具开关** — 设置页新增 Todo / 日程 / Obsidian 三项生产力工具开关，可分别控制入口显示与 Agent 工具可用性。
- **更新提醒增强** — 更新下载过期后自动刷新，并按期重复提醒处理更新。
- **适配 GLM-5.3-Flash 推理深度** — 模型注册与渠道管理适配 GLM-5.3-Flash 推理深度档位。
- **Agent 运行时升级 Pi 0.84.4**；计划模式允许只读 PowerShell。

### Bug 修复

- 修复无关文件预览被连带刷新；恢复 Git diff 汇总统计。
- 修复折叠侧边栏后的会话访问；文件目录状态与滚动位置跨切换保持。
- 修复终端光标跳动与输出裁剪；隔离 Windows 标题栏命中测试区域。
- Agent 流路由跨运行交接保留；后台文档任务隐藏终端。
- 允许用户手动关闭 Agent 打开的浏览器标签；受管浏览器正确渲染 favicon。
- 禁用系统刷新快捷键；移除改动页自动跳转与置顶用户消息条。
- Skills 面板 prompt 改动后立即填入当前会话。
- MCP 配置写入全面安全加固（完整配置写入校验、显式禁用、OAuth 代理、凭证绑定端点、代理转发远程 transport）。
- 委派结果强制收敛：协作子 Agent 必须收敛结果后才能继续主线。
