# Proma v0.19.53-jq.1 Release Notes

> 基线：官方 v0.19.53（upstream `f99edbdb`，含 v0.19.37 → v0.19.53 共 2 个官方 tag、19 个提交）；fork 自 `v0.19.37-jq.1` 起 0 个自有提交，本版全部内容为同步官方。

## 新功能（同步官方 v0.19.37 → v0.19.53）

### 连接与模型接入

- **MCP OAuth 一键登录**（#2037）— 支持 OAuth 的 MCP 服务（如 GitHub）点「授权」即打开浏览器完成登录，无需手动填 Token；OAuth MCP 连接可在界面内统一管理
- **GitHub Copilot 订阅额度可见**（#2025）— 侧边展示 Copilot 订阅剩余用量与重置时间
- **新增 Exa Search 连接入口**（#2040）— 「连接」目录新增 Exa Search 卡片，填 API Key 即接入 Exa 官方远程 MCP，获得语义网页搜索与页面内容提取；Key 加密存系统 Keychain，启用前先完成真实握手与工具发现验证
- **DeepSeek Flash 模型更新** — 适配 V4.1 Flash 思考深度配置（#2036）；模型 ID 统一更名为 `deepseek-flash`（#2042，DeepSeek 渠道与火山引擎 Coding Plan 预设同步跟随）；上下文窗口按 **1M** 计算（#2045），界面展示与用量统计与实际能力一致

### 界面与体验

- **Markdown 表格多行单元格编辑**（#2026）— 表格内输入长内容自动换行，不再需要横向拖动
- **左栏层级与滚动优化**（#2032/#2038）— 重排图标与间距，项目行与会话行对齐，会话行不再为委派状态预留右侧空槽
- **模型列表宽度自适应**（#2035）— 按窗口宽度自动加宽，长模型名完整显示
- **Skill 关闭/移除状态区分**（#2034）— 关闭时提示「已关闭」，不再误显示为「已移除」

## Bug 修复（选摘）

- **`~` 路径与本地图片**（#2030）— `~/xxx` 引用的文件可正常打开，消息内可渲染本地图片，读取失败时给出提示
- **Copilot 空 model catalog 不再报错**（官方 #2029 系）
- 中英文 README 版式更新（随上游；fork 安装入口保留）
