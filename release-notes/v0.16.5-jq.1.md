# v0.16.5-jq.1

基线：官方 v0.16.5（同步官方 17 个提交，含 v0.16.3、v0.16.5 两个官方版本）。

## 同步官方（v0.16.1 → v0.16.5）

**新功能**
- **Agent 灵动岛**：Mac 刘海屏原生仪表盘，显示需要接手的 Agent 与 1 小时内的待办/日程（#1375、#1376）；通用设置里可开关
- **语音听写流式反馈**：听写过程实时显示音量与转写文本（#1377）
- **拖拽引用文件**：从文件面板或系统直接拖文件/文件夹到 Agent 输入框作为引用（#1368）
- Composer 引用恢复 + 跨平台附件选择（#1356）
- 按会话筛选文件来源（#1354）
- 设置界面支持 ESC 退出并展示键帽提示（#1372）
- 下载完的更新在空闲时自动安装（#1360）

**修复与细节**
- 修复 Esc 后提及菜单重复弹出、@ 文件无匹配竞态（#1370）
- 修复经典视图 + 深色主题下设置面板左侧导航变白（#1371）
- Cmd/Ctrl+W 可关闭规划窗口（#1357）
- Codex OAuth 标题并行生成（#1361）、OpenCode Go 标题生成兜底加固（#1369）
- 滚动进度条与分屏分割线间距微调（#1365）

## 二开新功能

无（fork 自 v0.16.1-jq.2 起无自有新提交；「目录原生模式」已在 v0.16.1-jq.2 发布）。
