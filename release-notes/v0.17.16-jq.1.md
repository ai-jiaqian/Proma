# v0.17.16-jq.1 发版说明（草稿，2026-08-13 生成）

> 基线：官方 v0.17.15 + v0.17.16 两连发（published 08-11 / 08-12），同步 upstream/main 至 `751d25ce`。
> fork 自 v0.17.0-jq.1 起无自有提交，本版全部为同步官方内容。

## 同步官方 v0.17.15 + v0.17.16

### 内嵌受管浏览器自动化（v0.17.15 重头，v0.17.16 持续加固）

- Agent 可直接操作内置受管浏览器：打开网页、观察页面结构、点击/填写控件、切换标签页。
- 支持 `localhost` 本地开发服务导航（#1567）；站内搜索、登录后页面、动态内容、本地 HTML 预览均可交给 Agent。
- Agent 消息中的链接改为在内嵌浏览器打开（#1575）。
- 加固与修复：截图内容校验（#1570）、跨会话原生视图隔离（#1569）、Windows 下浏览器关闭按钮遮挡窗口控件（#1568）、网页搜索不足时自动回退（#1559）。
- 新增内置 Skill `in-app-browser`（现 v1.0.11）。

### 自动化（Automation）

- 支持「每周窗口化」定时任务（windowed weekly automations，#1581）。
- automation Skill v1.0.11 → v1.0.12。

### 界面与体验

- HTML 附件默认渲染、历史消息选区引用、turn 级 Skill 使用记录（chip 高度对齐 #1578）。
- 侧边栏会话列表虚拟化，长列表更流畅（#1571）。
- 灵动岛：空闲态展开时可收起/关闭（#1580）；已查看的错误不再持续提醒（#1562）；委派子会话不再显示在 Agent 岛（#1527）。
- 修复输入框抢焦点与草稿卡顿（#1579）。
- 会话列表可读性改进；Skills 列表开关时保持稳定（#1576）。

### 设备迁移与数据

- 设备迁移简化为单个 `.proma` 归档，移除 `.proma-backup` / `.proma-share` 文件关联。
- 孤儿数据清理默认关闭（#1577）。

### 修复

- 修复 Qwen、浏览器、自动更新的一批回归（#1574）。
- 重复 resume、MCP 会话恢复、预览崩溃防护等（v0.17.15）。
- Windows 窗口控制/拖拽修复（v0.17.1 批次，#1525）。
- worktree 持久化。
