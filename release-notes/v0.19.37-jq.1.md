# Proma v0.19.37-jq.1 Release Notes

> 基线：官方 v0.19.37（upstream `a987ec88`，含 v0.19.16 → v0.19.37 共 5 个官方 tag、75 个提交）；fork 自 `v0.19.5-jq.1` 起 0 个自有提交，本版全部内容为同步官方。

## 新功能（同步官方 v0.19.5 → v0.19.37）

### 平台与模型接入

- **新增 Linux 支持** — Ubuntu/Debian 发行基线，提供 `.deb` 安装包与 AppImage；安装与安全边界见官方 `docs/linux.md`
- **GitHub Copilot 订阅登录**（#2024）— 可直接用 Copilot 订阅额度接入模型
- **GPT-6 Astra 支持**（#1999）— 并将 Astra window 对齐 GPT-5.6（#2010）；适配 Gemini 3 thinking levels、Fable 5.1 思考档位（#1957/#1973）
- **Slack bridge**（#1997/#2022）— Slack 渠道接入，会话流与桌面端 UX 对齐

### 搜索方案重构

- **移除内置旧搜索/生图工具及配置入口**（#2008），改为 **Brave / Tavily MCP presets**（#1976）— 系统提示词相应调整为优先使用已启用的搜索类 MCP 工具

### Agent 与协作

- 委派子会话支持**指定/调整思考强度**（#1979；`thinkingLevel` + `set_delegation_thinking_level`）
- **单一委派观察 Tab 与未查看完成状态**（#1960）
- 计划模式：**审批时右侧只读预览计划文档**（#2018，`ExitPlanMode` 传 `planFile`）
- 拖动会话到输入框生成引用（#1968）；文件 chip 完整路径 Tooltip（#1967）
- **定时任务支持跨工作区创建**（`create_automation.workspaceId` + `list_workspaces`）

### 界面与体验

- Vault：可折叠文件侧栏（#1953）、**Obsidian 正文双链显示与跳转**（#2019）、新建文件夹即时显示（#1986）
- 项目区块一键折叠（#1992）；默认浏览器打开按钮（#1982）；搜索框响应式加宽（#1998）
- 工作区标签页鼠标滚轮横向滚动（#1950）；会话全量消息搜索索引（#1942）
- 系统提示词新增沟通原则：完整句、少比喻、不夸大（#1995）
- 移除 Proma 教程功能完整链路（#1984）
