### 新功能

**右侧工作区标签系统（重头）**
- **统一右侧工作区 tabs**（#1810/#1823）：右侧面板改为统一的多标签体系，会话产出、浏览器、预览等都在 tab 中切换。
- **探索会话标签**（#1819）：Agent 探索类会话以独立 tab 呈现。
- **可见的 Agent 终端 tabs**（#1835）：Agent 执行的终端以可见标签展示，不再黑箱。
- **Workstream 标签工作流**（#1839）：worktree 相关操作整合进标签流。
- **每个会话独立右面板布局**（#1815）、关闭后恢复上一个 tab（#1846）、tab 宽度跨标签稳定（#1834）、保留用户选择的 tabs（#1830）、活动 tab 始终可见（#1832）等一整套配套修复。
- **侧栏宽面板同时显示两种文件来源**（#1838）。

**浏览器原子操作工具（重头）**
- **新增一批固定原子浏览器工具**（#1816）：`BrowserFind`（按 role/name 定位）、`BrowserAct`（点击+等待合并）、`BrowserScroll`（数据化滚动）、`BrowserExtract`（抽取正文/区域文本）、`BrowserSelectOption`（原生下拉）、`BrowserHover`/`BrowserDrag`、`BrowserUpload`（已授权文件选择），减少任意 JS 执行。in-app-browser Skill 升到 1.1.1 完整引导。
- **浏览器直接打开 Agent 链接**（#1801）。

**文件与输入**
- **文件改动改用目录树展示**（#1798）：diff 面板层级更清晰。
- **统一输入工具栏与模型选择器交互**（#1797）。
- **终端输出 readback**（#1854）：Agent 能读回终端输出。

**其他**
- **归档会话按项目分组**（#1827）。
