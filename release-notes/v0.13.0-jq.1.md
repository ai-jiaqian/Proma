# Proma v0.13.0-jq.1

> fork 自分发版本（ai-jiaqian/Proma）。对比基准：官方 v0.13.0。上一 fork 版：v0.12.28-jq.1。
> **未签名**，macOS 首次打开需绕过 Gatekeeper（见下方安装说明）。

本版把官方 0.12.26 → **0.13.0** 的全部更新同步进来，并保留 fork 的「工作区记忆」体系与自分发能力。相对上个 fork 版（v0.12.28-jq.1），新增内容覆盖两批官方更新 + 一键安装脚本。

## 同步官方（相对上个 fork 版的新功能）

- **可见 agent 委派** — 新增内置 `collaboration` 工具，可创建真实可见、可停止、可追溯的协作子会话（区别于隐形 SDK SubAgent）；本版进一步增强：blocked 事件冒泡、continue delegation、GitBranch 图标。
- **Nowledge Mem 本地记忆卡片** — Chat 工具新增本地记忆能力。
- **Canvas 图片编辑** — Chat / Agent 中的图片可就地裁剪、旋转、画笔、矩形标注，改完发回对话；修复高分屏预览模糊。
- **mention 补全增强** — `/ # &` 补全面板补齐标题栏并统一快捷键提示。
- **自动任务会话归类** — 自动任务产生的会话归入专属虚拟项目组。
- **qwen-anthropic 渠道** — 适配 Qwen3.7 1M 上下文。
- **其他** — markdown frontmatter 元信息块渲染、默认 Skill frontmatter 修复、禁用 attribution block 提升第三方代理缓存命中率、多项 UI/主题修复（面板阴影、边框、模型选择器位置等）。

## 二开特性（fork 独有，持续保留）

- **工作区记忆体系（PROJECT.md）** — 每个工作区根的 `PROJECT.md` 每次会话自动注入 Agent 上下文；创建时 seed 模板、老工作区启动补建；知识管理走「内容路由表」+ 绝对路径提醒。
- **两个内置上下文 Skill** — `proma-dev-context`（开发）与 `proma-research-context`（科研），随默认 Skill 链路分发到所有工作区。
- **fork 自分发 + 一键安装脚本** — 发布与更新源指向 `ai-jiaqian/Proma`；新增 `scripts/install.sh`（macOS）/ `install.ps1`（Windows），一行命令安装/更新并自动绕过拦截。

## 安装（未签名，注意绕过拦截）

一键脚本（推荐）：
```bash
# macOS：安装 / 更新，跑一次更一次
curl -fsSL https://raw.githubusercontent.com/ai-jiaqian/Proma/main/scripts/install.sh | bash
# Windows
irm https://raw.githubusercontent.com/ai-jiaqian/Proma/main/scripts/install.ps1 | iex
```
或手动下载 DMG/exe：
- **macOS**：首次打开被拦截时，右键 app → 打开 → 确认；或终端 `xattr -dr com.apple.quarantine /Applications/Proma.app`。
- **Windows**：SmartScreen 警告 → 更多信息 → 仍要运行。
- macOS 暂无自动更新，后续新版需重新下载安装（或重跑安装脚本）。
