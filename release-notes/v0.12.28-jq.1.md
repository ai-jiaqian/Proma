# Proma v0.12.28-jq.1

> 首个 fork 自分发版本（ai-jiaqian/Proma）。对比基准：官方 v0.12.26。

这是本 fork 的第一个自发布版本，在官方 0.12.x 基础上叠加了「工作区记忆」体系与两个内置开发/科研上下文 Skill，并把发布与自动更新源切到本 fork。**未签名**，macOS 首次打开需绕过 Gatekeeper（见下方安装说明）。

## 新功能（相对官方）

- **工作区记忆体系（PROJECT.md）** — 每个工作区根的 `PROJECT.md` 每次会话自动注入 Agent 上下文，作为项目导航层；创建工作区时自动 seed 模板、老工作区启动时补建；知识管理提示词改为「内容路由表」（方向→PROJECT.md、过程→devlogs、调研→notes 等），并加绝对路径提醒，防止产出误落到会话目录。
- **两个内置上下文 Skill** — `proma-dev-context`（软件开发：dev.md 实时工作日志 + devlogs + 开发纪律）与 `proma-research-context`（科研：exp.md + experiment_records + 两条研究诚信纪律），随默认 Skill 链路自动分发到所有工作区。
- **fork 自分发** — 发布与自动更新源指向 `ai-jiaqian/Proma`，本 fork 可独立发版。

## 安装（未签名，注意绕过拦截）

- **macOS**：下载对应架构 DMG。首次打开被拦截时，右键 app → 打开 → 确认；或终端执行 `xattr -dr com.apple.quarantine /Applications/Proma.app`。
- **Windows**：SmartScreen 警告 → 更多信息 → 仍要运行。
- macOS 暂无自动更新，后续新版需重新下载安装。
