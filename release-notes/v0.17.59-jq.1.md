## 同步官方 v0.17.55 → v0.17.59（10 个提交）

**文件变更面板**
- 隐藏 `.claude`、`.context` 等隐藏目录（dotfile）的文件变动，diff 面板更干净（#1791）
- Agent 写入记忆（memory）的操作现在也展示在 diff 面板，改了什么一目了然（#1786）

**Agent 稳定性**
- 渲染进程被切到后台时新增 timer watchdog，Agent 流式输出不再被系统节流冻结（#1780）
- 排队消息改为原子提交，多条消息不再交叉竞态（#1787）
- 停止 Agent 时彻底清理所有恢复态运行时，不再留僵尸进程（#1784）
- 首次使用引导直接指向模型选择器，新用户不再卡在第一步（#1785）

**模型与通道**
- VisionRelay 正确路由 DeepSeek V4 Flash Exp 的视觉请求（#1788）
- 消除工具同步时的冗余 toast 提示（#1779）

**清理**
- 移除已废弃的内置 Chrome DevTools MCP，内置 MCP 清单与浏览器 Skill 引导同步更新（#1790）
- 删除 agent task 相关不可达死代码（#1789）
