# Proma v0.17.55-jq.1

> 基线：官方 v0.17.55（upstream/main `65c914ae`）。本版 = 官方 v0.17.55 全量 + fork 定制。

## 同步官方 v0.17.46 → v0.17.55（17 个提交）

**模型与通道**
- DeepSeek V4 Flash 支持原生视觉输入，新增 `deepseek-v4-flash-vision-exp` 候选（#1777）
- OpenCode 渠道按模型目录声明路由请求协议，推理档位不再与协议错配（#1774）
- 火山方舟 Coding Plan 改用套餐支持清单（Doubao Seed 2.1 Turbo、GLM-5.3、DeepSeek V4 等），不再显示未授权模型（#1767）
- 通义千问默认渠道迁移到 OpenAI 兼容端点（配置版本 v5），自定义端点不受影响（#1766）
- 飞书机器人支持飞书 / Lark 国际域名切换，二维码注册自动识别（#1773）

**通知音效**
- 新增 UISFX 通知音效库：12 套场景化音效包（arcade / cinematic / dreamy / glass / mechanical / minimal / organic / rubber / scifi / soft / studio / zen），CC0 资产，旧配置平滑迁移

**受管浏览器**
- Google 搜索页 3 秒未加载完成自动回退 Bing，国内网络不再长时间卡白（#1769）
- 放行内部自签名 HTTPS 证书，访问内网服务不再被拦截（#1768）

**Agent 与协作**
- 协作委派默认等待 30 → 60 分钟、上限延长至 2 小时，长任务不再被超时打断（#1770）
- AskUserQuestion 自由输入等待 2 → 15 分钟，从容作答（#1772）
- Agent 提示词进度更新引导增强，长任务阶段进展更清晰（#1776）

**其他修复**
- 关闭 MCP 服务编辑器后自动刷新测试状态（#1771）
- 编辑器返回后恢复自动化定时任务列表（#1763）
- 恢复屏幕外窗口边界，窗口不再「失踪」（#1756）
- 保留 Claude 自适应思考标记（#1755）
- 移除会话工作区不匹配拒绝，外部触发（如飞书镜像）请求更稳定（#1750）
