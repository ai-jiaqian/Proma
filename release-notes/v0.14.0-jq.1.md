# Proma fork v0.14.0-jq.1

> 基线：官方 package.json version 0.14.0（upstream `db444c50`，官方已发 v0.13.28 / v0.14.0 release）。本版为「跟随官方发版」——同步官方 21 个提交，fork 自有改动无新增。
> 不签名、手动下载安装。

## ⚠️ 重要变更：记忆机制切换

- **移除 MemOS Cloud 云端记忆全链路**：删除内置 `mcp__mem__*` 记忆 MCP、MemOS HTTP 客户端、Chat 记忆工具与相关配置（#1047）。
- **改用工作区文件记忆**：记忆改由 Claude Agent SDK 维护在工作区根的 `.claude/memory/`（`MEMORY.md` 为索引），并新增可视化「工作区记忆」Tab——可查看文件树、直接编辑、自动保存；生成记忆时会沉淀用户画像 `user-profile.md`。
- **影响**：旧的 MemOS 云端记忆不再注入；如需保留原有记忆，请迁移到新的工作区记忆目录。
