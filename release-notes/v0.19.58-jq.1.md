## 新功能（同步官方 v0.19.53 → v0.19.58）

### 模型

- **新增 GLM-5.3-FlashX**（#2077）— 模型列表新增 GLM-5.3-FlashX
- **新增小米 MiMo-V2.6 系列**（#2088）— 支持小米 MiMo-V2.6 系列模型，同时退役旧版 MiMo presets
- **GPT-6 目录支持**（Codex 渠道）— channel/model 目录新增 GPT-6 系列
- **移除已退役的 Codex Spark** — 模型列表清理
- **移除 OpenCode Go 渠道支持**（09-24）— ⚠️ 若你配置过 OpenCode Go 渠道，升级后该渠道不再可用，请改用其他渠道
- **移除火山方舟 Plan 渠道**（#2089，09-24）— ⚠️ 退役 `doubao` 与 `ark-coding-plan`（火山方舟 Token Plan / Agent Plan / Coding Plan）存量渠道，渠道数据迁移 v6→v7 时自动删除；**火山引擎 API 普通渠道保留不受影响**。若你在用火山方舟 Plan 类渠道，请改配火山引擎 API 渠道

### 界面与体验

- **Markdown 表格编辑改进** — 删行/删列后焦点自动归位、最少列数保护、编辑中单元格草稿内容保留，长表格编辑不再丢光标
- **新会话右栏默认 460px** — 新会话不再继承旧全局宽度，各会话布局偏好独立
- **Bridge 会话自动命名** — 微信等 bridge 会话按内容自动起名，不再是无意义的默认标题

## Bug 修复（选摘）

- **Diff 面板激活标签页自动显现**（#2090）— 激活的 workspace tab 不再被隐藏，Diff 面板标签栏行为修复
- **删除会话时同步关闭浏览器**（#2078）— 删会话不再遗留后台浏览器进程
- **Agent 任务进度同步修复**（#2076）— 可见任务进度与实际状态保持一致
- **文件路径 chip 只渲染可解析路径** — Agent 输出中的路径 chip 不再显示无法打开的无效路径
- **微信 Agent 消息处理稳定性**（9 文件）— WeChat bridge 消息链路加固
- **侧栏控件提示样式统一** — 左栏各控件 tooltip 视觉一致
