# Proma fork v0.14.6-jq.1

> 基线：官方 upstream/main（package.json 0.14.6，最新 release v0.14.5）。本版纯同步官方 29 提交，无 fork 自有新功能。不签名 · 手动下载。

## 同步官方（自 v0.14.0-jq.1 起 29 提交）

### 新功能 / 体验
- 输入框 Markdown 渲染开关（#1080）
- 协作子会话触发策略更积极：对抗式审查 + 多样性探索（#1074）
- Agent 运行中输入进入可见托管队列（#1075）
- 前 5 次自动重试静默进行，避免瞬时波动惊扰用户（#1078）
- 通知音改用 Web Audio API，修复蓝牙设备破音、防 GC 回收导致声音截断（#1081-review/#1082/#1083）

### 修复 / 加固
- 全仓 rmSync/renameSync EBUSY 加固 + 提取 fs-retry 共享模块（#1089）
- Windows 跨工作区迁移会话目录 EBUSY 修复（#1028）
- chips 支持 Windows 反斜杠/正斜杠路径分隔符（#1085/#1086/#1026）
- file-chip 右键菜单 z-index 提升，避免被终端暗色主题遮挡（#1027）
- contextWindow 不再被子代理模型条目拉低（#1073）
- 禁用 Tool Search 以修复 HTTP MCP 工具注册（#1072）
- 禁用 SDK workflows（#1071）
- 移除 agent 自动批准模式（#1068）
- DeepSeek 上下文恢复处理（#1070）
- 修复 agent MCP discovery scope（#1069）
- agent resume session 恢复（#1067）
- 后台等待中发送失败时恢复输入框内容（#1076）
- 内置 MCP 详情面板关闭按钮失效修复（#1050）
- 侧边栏与文件面板按钮尺寸/间距对齐（#1051）
- 侧边栏时间标签抖动 / 会话结束回弹修复（#1066/#283d224b）
- 移除过时的 context-1m beta header（#1053）

### 内部 / 依赖
- @anthropic-ai/claude-agent-sdk 0.3.197 → 0.3.201（#1087）
- 移除自定义 auto compact 设置（#1077）
- 提取路径分隔符常量、codex 优化知识维护提示词（#1086/#1081）

## ⚠️ 需人工关注的行为变更
- **#1071 禁用 SDK workflows / #1072 禁用 Tool Search**：fork 的 Workflow / ToolSearch 相关能力会受影响；同步前确认这两项对 fork 的多 Agent/工作流场景是否可接受。
- **#1074 协作策略 + #1081 知识维护提示词**：均改 `agent-prompt-builder.ts`，与 fork 的 `KNOWLEDGE_MANAGEMENT_SECTION` 冲突，需人工逐段合并（见 commands 文件）。

## 安装
不签名版本，需手动下载 DMG 后 `xattr -dr com.apple.quarantine /Applications/Proma.app`，或用一键脚本：
`curl -fsSL https://raw.githubusercontent.com/ai-jiaqian/Proma/main/scripts/install.sh | bash`
