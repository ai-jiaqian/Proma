# Proma fork v0.15.3-jq.1 更新

> 同步官方 `v0.15.3`（upstream package.json 0.15.3）。自 fork 上次发版 `v0.14.20-jq.1` 起，无 fork 自有新功能，本次纯同步官方 47 个提交。
> 不签名手动下载版本。安装见 README 中的 install.sh。
> 本批引入 Pi Agent SDK（第二套 Agent 运行时，实验性、默认关闭，Claude 仍为默认内核）。

## 同步官方 · 新功能

### Pi Agent 运行时（v0.15.0 主特性）
- 内置第二套 Agent SDK（`@earendil-works/pi-agent-core@0.80.3` 等），Claude 为默认内核，Pi 可在实验性设置中开启
- Pi web 工具、用户 MCP 工具桥接、Pi channel 不进 Claude 白名单
- 支持 OpenAI Responses channels (#1176)
- Automation 支持 Pi Agent runtime (#1174)

### Codex / Pi 增强（v0.15.1 ~ v0.15.3）
- 查看 ChatGPT Codex OAuth 订阅额度 — Agent 上下文用量与渠道卡片展示滚动额度、剩余百分比与重置时间 (#1188)
- ChatGPT Codex 快速模式 — Pi Runtime 下用受支持 Codex 模型时，会话工具栏可切「快速」模式，随会话保存 (#1190, #1192)
- Codex OAuth 代理支持 — 授权码换取/刷新 Token 复用 Proma 全局代理设置 (#1189)

### 其他功能（v0.15.0 批）
- 支持 Kimi K3 上下文 (#1168)
- 会话快速切换快捷键
- 显示服务商套餐额度

## Bug 修复与打磨

### Pi runtime 修复（v0.15.1 ~ v0.15.3）
- 修复 Pi 写文件参数不完整（要求 write 同次提供路径 + 完整 content）(#1184)
- 优化 Pi 工具调用流式预览（预览阶段不重复传累计参数，降 IPC/渲染压力）(#1185)
- 修复历史记录中相对路径预览（补会话工作目录解析上下文，`.context/plan/*.md` 等可正确打开）(#1186)
- 修复飞书 Pi 流式消息重复/乱序（正确处理累计 partial 帧）(#1187)
- 优化 Pi 流式输出性能（高频 partial 合并为最高 20fps 快照）(#1191)

### UI / 通用修复（v0.15.0 批）
- 修复嵌套滚动溢出 (#1182)
- 设置页 memory 段移至底部 (#1181)
- plan mode 输入框虚线边框圆角对齐 (#1173)
- thinking 文本保持常规字重 (#1172)
- 修复打包后 runtime 依赖解析（`sync-runtime-deps.ts`，与 Pi runtime 相关）
- Skill 扫描对 dangling/broken symlink 容错
- 修复 Agent 1M 模型后缀路由 (#1152)
- 修复 Agent compact provider 上下文窗口处理 (#1151) 及 provider window 相关多处
- Windows 项目创建加固（保留字 slug 处理）(#1166)
- 限制 SDK max output override 仅对 claude 生效 / 修复 Agent SDK 输出 token 上限
- 修复小米 token plan 鉴权头
- markdown linkify：关闭模糊匹配，避免 SKILL.md 等文件名被误判为内联链接
- 智谱凭据解析去重、统一套餐额度缓存（内部重构）
- 澄清工作区 memory 提示词路径 (#1157)
