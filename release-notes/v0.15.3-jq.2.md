# Proma fork v0.15.3-jq.2 更新

> 同步官方 `v0.15.3` 之后的 5 个提交（upstream package.json 仍 0.15.3，无版本 bump）。基线仍 0.15.3，jq 后缀递增为 `.2`。
> 自 fork 上次发版 `v0.15.3-jq.1` 起，无 fork 自有新功能，本次纯同步官方 5 个提交。
> 不签名手动下载版本。安装见 README 中的 install.sh。

## 安全修复

### IM Bridge 日志脱敏 (#1204)
- 新增 `bridge-log-redaction.ts`，对飞书 / 钉钉 / 微信 bridge 的敏感日志（token、密钥等）统一脱敏
- 覆盖 `bridge-binding-store` / `bridge-command-handler` / `bridge-registry` 及三个 bridge 的 manager / config
- **用 IM bridge 的用户建议更新**，避免敏感凭据泄露到本地日志

## 新功能

### Pi session fork 与 rewind (#1203)
- Pi Agent 会话支持 fork（从某点分叉）与 rewind（回退到某点）
- `pi-agent-core` / `pi-ai` / `pi-coding-agent` 升级 `0.80.3 → 0.80.10`
- `agent-session-manager` / `pi-model-registry` / `pi-agent-adapter` / `codex-oauth-service` 配套调整

### 会话级 OpenAI reasoning 控件 (#1201)
- Pi Codex 会话可调节 thinking / reasoning 强度
- 新增 `agent-thinking-level.ts` 与 `pi-codex-request-settings.ts`，AgentView 提供控件 UI

## Bug 修复与打磨

### Pi Codex proxy 修复 (#1196)
- 重构 `pi-agent-adapter`，抽出 `pi-request-proxy.ts` 处理代理请求，修复 Pi Codex 走代理时的请求问题

### UI 清理 (#1202)
- 移除 context usage freshness indicator（已无用的上下文新鲜度指示器）

## 升级说明

- **mac**：重新下载安装（不签名无自动更新）。Apple 芯片选 `arm64`，Intel 选 `x64`；首次打开若被 Gatekeeper 拦截，终端跑 `xattr -dr com.apple.quarantine /Applications/Proma.app`。
- **Windows**：App 每 4h 自动更新；或重新下载 `.exe` 安装。
- 一键脚本：`curl -fsSL https://raw.githubusercontent.com/ai-jiaqian/Proma/main/scripts/install.sh | bash`

> Pi Agent runtime 仍为实验性、默认关闭，Claude 仍为默认内核。本批 Pi/Codex 增强对默认 Claude 流程无影响。
