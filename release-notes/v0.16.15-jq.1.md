# v0.16.15-jq.1

基于 upstream/main `b9ffde53`（官方包版本 0.16.15，包含 v0.16.10 及其后 11 个 main 提交）+ fork 二开定制。

## 核心架构升级

- **Agent 运行时全面迁移到 Pi-only**（#1498 / #1499 / #1501）：移除旧 Claude runtime、相关依赖与残留类型，统一 Agent/Automation/协作运行链路
- **工作区规则迁移到 AGENTS.md**（#1504）：项目指令由 Pi 管理受信任来源（#1459）；Proma 受管工作区的旧 CLAUDE.md 自动迁移，用户项目旧规则经核验后兼容迁移并保留原文件；本地项目指令改为显式解析和注入
- **移除自动本地记忆召回**（#1508）与 Nowledge 集成（#1507），避免重复或不可控的上下文注入
- Windows shell 改为可选（#1505），启动不再把 Node 检测作为 Agent 前置条件

## 官方 v0.16.10 功能与修复

- 设置中新增**重放新手引导**入口（#1435），引导页补充滚动提示（#1436 / #1493）
- 侧边栏恢复「新建会话 + 搜索」并排布局（#1472）
- Todo 列表分割线与边框更清晰（#1438）
- Agent Island 只保留 macOS 原生实现，移除 Electron fallback（#1489）；运行中状态优先显示（#1500）
- 修复长草稿光标跳动（#1486）、git diff 刷新循环（#1484）和会话文件状态标记不一致（#1503）

## fork 二开保留

- 发布与更新渠道继续指向 `ai-jiaqian/Proma`，采用不签名、手动下载方案
- 继续剔除 git commit / PR 的 `Made-with: Proma` 推广标识
- 保留 Proma 托管项目文件播种；本地项目的 AGENTS.md / 旧规则迁移改由上游新指令架构承接

## 安装

1. 在 Releases 页面下载对应平台产物
2. macOS 下载 DMG 后拖入 Applications 替换旧版
3. 首次打开若提示未签名：系统设置 → 隐私与安全性 → 仍要打开
