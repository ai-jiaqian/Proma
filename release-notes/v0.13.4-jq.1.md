## 同步官方（v0.13.0 → v0.13.4）

### 新功能

- **定时任务 once 一次性调度 + maxRuns 运行次数上限** — `once` 调度类型通过绝对时间戳在指定时刻只跑一次，跑完自动停用（重启后过期任务补跑一次）；`maxRuns` 正交于所有调度类型，按实际执行次数计，达上限自动停用。UI 新增「仅运行一次」频率项 + datetime 选择器、运行次数上限输入、「已完成」分组。让「未来某时间点跑一次 / 跑有限几次就停」的延时任务也能纳入自动化体系。(#914)
- **经典 / 现代界面风格** — 外观设置新增两套界面风格切换。(#915)

### Bug 修复（稳定性主线）

- **并发会话同步写风暴修复** — 生产构建中多 Agent 并发时，`onSessionId` 守卫失效导致每条 SDK 消息都全量原子写会话索引，wedge 主进程事件循环、UI 阶段性冻结（彩虹条、悬浮预览延迟）。dev 环境无法复现，仅生产暴露。修复后仅在会话 ID 真正变化时持久化一次。(#910)
- **长任务断连后上下文保留** — 网络断连后编排层误清 `sdkSessionId`，丢失指向 SDK 磁盘完整历史的 resume 指针，模型从零重做。修复后断连 / 5xx / 未知错误不再清除指针，并扩展断连错误模式覆盖。(#903 / #905)
- **SDK 0.3.185 iterator 终止语义适配** — 消除 v0.13.0 升级 SDK 后每会话白白浪费的 2 秒 drain timeout。(#913)
- 推荐条发送后保留草稿 (#904)；有序列表 Shift+Enter 续项修复 (#908)；附件 chip 支持点击预览 (#906)；轻量主题代码选区对比度优化 (#911)；预览面板切换保留 AskUserQuestion 草稿 (#912)；移除 auto preview toggle (#909)。
