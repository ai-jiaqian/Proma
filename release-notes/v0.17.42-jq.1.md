> 基于官方 v0.17.42（upstream `28ca96a5`）。fork 上一版 v0.17.40-jq.1 基于官方大回滚前的 0.17.40 线；本版切换到官方回滚后重铺的 v0.17.42 线（v0.17.26 基线 + 修复重铺 + 新增），并吸收其后 11 个新提交。fork 无自有新功能。

## 同步官方 v0.17.42

### 新功能 / 体验提升

- **系统性能大幅提升**：流式输出改为分块记忆化渲染，不再每帧全量解析 Markdown；代码高亮按语言缓存复用。修复长会话累积性卡顿（单 Agent 跑 20 分钟后按键延迟 38ms→185ms 的问题）：批量复制 delta、索引解析缓存、后台会话运行态回收、消息批量追写等多处高成本路径重写；多会话并行流式时后台流自动降级。
- **Pi 运行时升级并迁入独立进程**：Pi 0.84.2 托管到独立 Electron 工具进程（Proma Runtime），与主界面隔离，单点故障不拖垮整个应用。
- **新模型预设**：GLM-5.3（智谱 / OpenCode Go / 火山方舟 Coding Plan，1M 上下文、官方 thinking 开关）；Doubao Seed 2.1 Pro / Turbo（火山方舟，256K）。
- **受管浏览器跨标签跟随、可关闭**：切换标签不丢 Agent 操作上下文；Agent 可主动关闭受管浏览器（需用户批准）。
- **会话切换动画与流式平滑**：会话/历史切换带轻量过渡动画（遵循系统减少动态效果），标签切换延迟移除。
- **规划工作流精简**：Todo 规划流程更顺畅，恢复 prompt-clarifier 等 Skills。
- **渲染进程崩溃自动恢复**：崩溃后自动重启恢复，失败时给兜底诊断页，不再白屏。

### 修复

- 会话标题自动重命名失败修复（含自定义渠道失败回退）。
- Agent 流式输出跟随修复（#1723）；AskUserQuestion 等待响应修复（#1716）；队列消息状态修复（#1717）。
- 语音输入重启前生命周期重置（#1719）；会话级文件面板修复（#1715）。
- 侧栏归档会话懒加载（#1713），长列表更省资源。
- 大回滚后重铺的一批修复：标题与工具显示恢复、transcript 虚拟化、渲染卡顿与进程恢复、流式历史折叠、浏览器 jank/私网导航与下载等。
