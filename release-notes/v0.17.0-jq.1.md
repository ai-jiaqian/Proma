# Proma v0.17.0-jq.1 更新（草稿，2026-08-10 生成）

> 基线：官方 v0.17.0（a673bbae）。fork 侧无自有新提交，本版 = 同步官方 v0.17.0 增量。
> 说明：官方 v0.17.0 notes 里的「Pi-only 运行时 / AGENTS.md 受信指令 / 移除 Nowledge」等大项，fork 已在 v0.16.15-jq.1 提前同步发布过，故不在本 notes 重复；以下只列 fork 用户实际新增的部分（官方 v0.16.10 之后的 16 个提交）。

## 新功能

- **工作区记忆维护升级** — 重构工作区知识维护流程：新增记忆变更追踪与刷新服务，Agent 写入记忆后界面出现更新提示，保持记忆索引同步；`knowledge-maintenance` 技能新增自组织维护指引；工作区记忆页简化，重点信息更聚焦。（官方 #1512/#1513/#1515）
- **队列消息后台发送 + 立即打断** — 运行中发送的消息进入队列后会在后台继续发送，不再静默等待运行结束；排队时新增 toast 提示与「立即打断」发送入口。（官方 #1511/#1520）
- **上下文压缩二次确认** — 手动压缩按钮改为「点击两次确认」触发，第一次点击进入警示色确认态，3 秒无操作自动重置，避免误触清空上下文。（官方 #1278）

## Bug 修复

- **灵动岛运行体验** — 修复运行中关闭灵动岛后被流式事件立刻重新弹出的问题；正在运行的会话只有状态切换（需要交互/出错/完成）或新会话才重新弹出；修复运行中灵动岛 dismiss 卡住的问题。（官方 #1520）
- **Agent 可访问会话附件之外的文件** — 文件浏览器与差异查看中打开的文件现在也能直接交给 Agent 处理。（官方 #1522）
- **代理设置生效于网络搜索与 Chrome MCP** — 系统代理设置同样应用到 Tavily 网络搜索与 Chrome DevTools MCP，并优化启动逻辑避免代理与 MCP 初始化互相阻塞。（官方 #1516）
- **Git 变更面板扫描优化** — 统一仓库扫描缓存与一致性基准，避免重复扫描造成的卡顿；会话文件状态标记显示一致。（官方 #1480）
- **预览标签页文件面板快捷键修复** — 「切换文件面板」快捷键在预览标签页中恢复生效。（官方 #1521）
- **引用历史后输入框失焦修复** — 从历史记录引用条目后，输入焦点正确回到对话输入框。（官方 #1494）
- **模型选择器加宽** — 长模型名不再被截断。（官方 #1517）
