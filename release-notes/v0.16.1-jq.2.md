# Proma v0.16.1-jq.2

> 基线：官方 v0.16.1。fork 后缀 .2：新增 fork 自有功能「目录原生模式」。

## fork 自有新功能：目录原生模式（跨 harness 共享项目记忆）

**核心变化：从本地文件夹创建的项目，Proma 不再使用私有记忆体系，改用业界通用的 `AGENTS.md`。**

- **AGENTS.md 解禁**：此前 Proma 会显式过滤本地项目根的 `AGENTS.md`（Pi 引擎原生支持读取）。现在从本地文件夹创建的项目，`AGENTS.md` 由 Pi 原生加载——**与 Codex / OpenCode / Pi CLI 等工具无缝共享同一份项目记忆**，在终端和 Proma 之间切换不再丢失上下文
- **本地项目停用 Proma 记忆注入**：不再注入 PROJECT.md 与知识管理提示词段；系统提示词引导 Agent 把项目长期知识写入项目根的 `AGENTS.md`
- **一个项目 = 一个工作目录**：本地项目下所有会话直接在你的目录中工作（cwd=项目根），文件区显示真实目录内容
- **两类项目互不干扰**：Proma 托管项目（未绑定目录）维持原有 PROJECT.md 记忆体系不变；`CLAUDE.md` 仍被过滤（避免与 Proma 提示词体系双注入）
- 测试：prompt-builder +3 用例、resource-loader override +1 用例（锁定 AGENTS.md 保留 / CLAUDE.md 剔除）
